# KOTWARI INTERNATIONAL LTD.

## MASTER CORPORATE WEBSITE DEVELOPMENT PROMPT

Create a premium, modern, scalable, multilingual corporate website for:

**Company Name:** Kotwari International Ltd.
**Master Brand:** Kotwari™
**Brand Tagline:** “Gao Se Global Tak”
**Core Philosophy:** Village → Farmer → Processing → Brand → Market → Global Customer

The website must position Kotwari as an emerging Indian integrated agriculture, food, FMCG, retail and rural-commerce company connecting farmers and village production directly with organized domestic and international markets.

The website should NOT look like a small local FMCG company website.

It should visually feel like a combination of:

- Premium global FMCG company
- Agri-tech ecosystem
- Farmer producer network
- Food processing company
- Modern retail group
- Export-oriented Indian enterprise
- Investor-ready corporate group
